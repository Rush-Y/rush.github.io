Hotpin 사용 가이드

AI로 만든 동적 HTML 와이어프레임에 바로 설명을 남기고, 디자이너·퍼블리셔·개발자가 같은 화면에서 확인하는 크롬 확장 프로그램

Why Hotpin

기획 의도

AI로 만든 와이어프레임 위에 기획자의 설명을 그대로 남겨서, 팀원이 피그마로 옮기거나 캡쳐하지 않고 같은 화면에서 바로 확인하게 하기 위해 만들었습니다.

기존 방식
별도 문서·피그마에 옮겨 적어야 했고, 그 과정에서 위치 정보가 소실되거나 내용이 여러 곳에 흩어짐
→
Hotpin
설명을 "그 자리에 직접" 남겨서, 정보와 화면이 항상 함께 붙어있음
🔥
Hot — key
마우스 대신 단축키로 대부분의 기능을 처리. AI가 만든 HTML 자체가 이미 완성된 화면처럼 보여서, 클릭형 버튼을 넣으면 "서비스 기능인지 Hotpin 기능인지" 헷갈리기 때문이에요.
📍
Pin — description
원하는 지점에 핀을 꽂듯 설명을 남겨요. 번호 뱃지로 표시되고, 그 요소에 계속 고정돼요.
Installation

설치 방법

크롬 웹스토어에 등록된 확장이 아니라, 폴더를 직접 불러오는 방식입니다. 설치에 3분이면 충분합니다. 크롬(또는 엣지·웨일 등 크로미움 계열 브라우저)에서 진행해주세요.

hotpin-extension-v0.1.0.zip Google Drive · 약 90KB 다운로드

Drive에 버전 번호가 더 높은 파일이 있으면 그걸 받으세요.

1
파일 받기
위 버튼으로 Drive에 접속해 hotpin-extension-v0.1.0.zip을 다운로드합니다.
2
압축 풀고 자리 잡기
압축을 해제한 뒤 폴더를 계속 둘 위치로 옮깁니다. (예: 문서 폴더)
3
개발자 모드 켜기
주소창에 chrome://extensions 입력 → 우측 상단 개발자 모드 스위치 ON
4
폴더 불러오기
좌측 상단 압축해제된 확장 프로그램을 로드 클릭 → 2번에서 옮긴 hotpin-extension 폴더 선택
5
설치 확인
목록에 핫핀 (Hotpin) 카드가 생기고 툴바에 아이콘이 보이면 완료입니다.
6
파일 접근 허용 (필수)
핫핀 카드의 세부정보 → 파일 URL에 대한 액세스 허용 스위치를 켭니다. 이걸 켜지 않으면 내 컴퓨터에 있는 HTML 파일에서 핫핀이 동작하지 않습니다.
7
동작 테스트
와이어프레임 HTML을 열고 / K를 눌러 단축키 팝업이 뜨면 정상 동작합니다.
6단계를 건너뛰지 마세요. 설치는 끝났는데 단축키가 전혀 안 먹는다면 거의 항상 이 스위치가 꺼져 있는 경우입니다. 크롬은 보안상 내 컴퓨터에 있는 파일(file://로 열리는 HTML)에는 확장 프로그램을 기본적으로 적용하지 않기 때문에, 설치와 별개로 한 번 직접 허용해줘야 합니다.

화면으로 보기

3~6단계가 처음이면 낯설 수 있어서, 실제 화면 구성을 그림으로 옮겼습니다. 크롬 버전에 따라 문구나 위치가 조금 다를 수 있습니다.

설치 전 꼭 알아두기

• 폴더를 지우거나 옮기면 확장이 멈춥니다 — 크롬은 그 폴더를 계속 참조합니다. 다운로드 폴더에 임시로 두지 말고, 처음부터 고정 위치에 두세요.

• 폴더를 선택할 때 한 겹 더 들어가 있지 않은지 확인 — 선택한 폴더 안에 manifest.json이 바로 보여야 합니다. 압축 해제 방식에 따라 같은 이름의 폴더가 두 번 겹칠 수 있는데, 그때는 안쪽 폴더를 선택하세요.

• 자동 업데이트가 되지 않습니다 — 새 버전이 공유되면 파일을 다시 받아 기존 폴더에 덮어쓰고, chrome://extensions에서 핫핀 카드의 새로고침(↻) 버튼을 눌러주세요. 지금 쓰는 버전은 같은 화면의 핫핀 카드에 표시되니, Drive의 파일명과 비교해보면 됩니다.

• 확장 프로그램 없이 열람만 하려면 설치가 필요 없습니다 — 저장된 파일에는 조회 전용 뷰어가 함께 들어있습니다. 직접 핀을 작성·수정할 사람만 설치하면 됩니다.

• 다른 사이트에서 / 검색 단축키가 안 먹습니다 — 핫핀이 /를 기능 키로 쓰기 때문에, 설치 후에는 GitHub·YouTube·Notion 등에서 /로 검색창을 띄우는 동작이 막힙니다. 버그가 아니라 알려진 동작이고, 핫핀을 쓰지 않는 동안에는 툴바의 핫핀 아이콘을 눌러 끄기로 돌려두고 페이지를 새로고침하면 원래대로 돌아옵니다.

참고. 크롬을 재시작할 때마다 "개발자 모드 확장 프로그램을 사용 중지하세요" 경고창이 뜰 수 있습니다. 웹스토어를 거치지 않은 확장에 대한 안내일 뿐이니 닫으셔도 동작에 영향은 없습니다. 만약 회사 정책으로 관리되는 브라우저에서 개발자 모드가 아예 꺼져 있거나 로드가 차단된다면, 설치가 불가능한 환경이니 문의 주세요.
How to use

사용 방법

확장 프로그램 설치 후, 와이어프레임 HTML 파일을 열면 아래 흐름으로 사용합니다.

1
자동 인식
파일을 처음 열면 마커가 자동으로 심어져 "직접 만든 와이어프레임"으로 인식됩니다.
2
조회 모드
/ H로 저장된 디스크립션 뱃지를 보이거나 숨깁니다.
3
편집 모드 진입
/ A → 어드민 비밀번호 입력 (세션 동안 재입력 불필요)
4
핀 찍기
화면의 원하는 요소를 클릭 → 수정 타입 선택 → 타이틀·본문 작성
5
저장
/ L로 로컬 파일에 저장(같은 파일에 자동 덮어쓰기)
6
팀 공유
저장된 파일을 GitHub 등에 올리면, 팀원이 그 링크를 열 때 최신 내용이 자동으로 채워집니다.

단축키

단축키동작
/ H디스크립션 넘버링 뱃지 보기/숨기기
/ A어드민 비밀번호 입력 → 편집 모드 진입
/ B편집 모드 → 조회 모드로 복귀
/ L현재 와이어프레임을 로컬 파일로 저장(덮어쓰기)
/ K단축키 목록 팝업 보기

/를 누르면 약 1.5초 동안 다음 키 입력을 기다립니다. 그 안에 h/a/b/l/k가 아닌 다른 키를 누르면 취소됩니다.

알아두면 좋은 점

• 공통 핀 — 헤더처럼 모든 화면에 공통으로 뜨는 요소는 작성 시 "공통" 옵션을 켜면, 화면이 바뀌어도 항상 노출되고 번호도 공통1, 공통2…로 별도 관리됩니다.

• 요소를 계속 따라가는 핀 — 정렬/필터가 바뀌거나 요소가 드래그로 다시 그려져도, 그 요소 고유의 식별자를 기준으로 핀이 계속 따라갑니다.

• 확장 프로그램 없이도 열람 가능 — / L로 저장하면 조회 전용 뷰어 코드가 파일 안에 함께 구워집니다. Hotpin이 설치되지 않은 팀원도 파일을 열기만 하면 뱃지를 클릭해 내용을 볼 수 있습니다(열람만 가능, 수정 불가).

Tip. 처음 / L을 실행하면 저장 위치를 한 번 선택해야 하고, 이후로는 같은 파일에 자동으로 덮어씁니다. 저장하지 않고 새로고침하면 그 사이 작성한 핀이 화면에서 사라질 수 있으니, 작업 중간중간 저장해주세요.
